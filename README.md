# 华夏千年历史长卷

静态网页项目，主入口为 `index.html`，地图入口为 `jiangshan-atlas.html`。可以直接打开主入口，也可以通过静态 HTTP 服务访问。部署时需保留各资源文件的相对目录关系。

## 当前运行文件

- `index.html`：长卷 DOM、外部资源入口。
- `scroll-app.js`、`scroll.css`：长卷数据、控制逻辑和样式。跨页联动已合并至控制逻辑，无需另加覆盖补丁。
- `emperor-data.js`：明确列举的在位皇帝资料。
- `jiangshan-atlas.html`：地图 DOM 与启动种子。
- `atlas-app.js`：地图控制器、长按年份尺与微调。
- `atlas-bridge.js`：长卷与地图的消息联动。
- `atlas-ui.js`：可移动图例、档案标签及面板布局。
- `atlas.css`、`atlas-timeline-ui.css`、`view-switch.css`：地图样式、图例与年份尺样式、两页共享切换样式。
- `atlas-dynasty.js`、`atlas-lore.js`、`js/atlas_snapshots.js`、`atlas-terrain.webp`：地图数据和地形。

## 维护与构建

当前页面使用上述拆分资源。修改功能时，直接修改相应 JS / CSS，不再向 HTML 尾部叠加重定义补丁。历史资料与可见功能分开核对，不能仅按某一屏没有出现就删除数据或样式。

`jiangshan-atlas.src.html` 保留地图的数据打包源，控制器、界面与样式共享当前运行文件，不再复制另一份实现。`python split_atlas.py` 可以从该源重建地图骨架和数据资源；脚本按内容标记识别源文件，不依赖文件体积，并支持旧的完整单文件输入。构建仍会覆盖地图骨架和数据资源，因此修改相关数据时应同时维护打包源。

`chinese-dynasty.html` 与 `_probe/` 属于历史入口、参考资料和旧构建/检查工具，未列入主入口依赖。本次保留，以免删除仍被单独打开的历史内容；日常运行和本轮维护无需调用旧生成器。

## 本轮回归范围

长卷拖动/缩放、事件/人物/盛世切换、235 位帝王牌、1949 年末端、详情与检索、人物跳转地图及返回、沿革查询、档案收展、图例拖动、长按逐年微调、桌面与手机布局。功能截图与性能记录保存在本次维护工作目录。
